# 贴边快捷菜单与本机 API 调用记录

## 入口与行为

- 设置中的「快捷操作」开关仍负责显示/隐藏入口。
- 快捷入口始终贴边半隐藏；拖动松手后吸附最近一侧，并记住停靠侧和纵向比例。它不再参加提示词查看器的双球排列。
- 点击入口显示独立菜单：API 设置、小卷悬浮窗、世界书设置、API 调用记录。
- API 与世界书保留全局/角色范围和原有绑定逻辑，并提供完整设置页入口。新增与编辑世界书内容仍使用原来的完整设置页。
- 从快捷菜单打开小卷时不额外显示小卷悬浮球，关闭面板后直接收回；对话不清空。原有从桌面组件激活小卷的路径不变。
- 调用记录也可从「设置 → API 设置 → 查看调用记录」进入。

## 日志范围

- 复用本机模型调用日志环，不是服务商控制台，不会自动接入服务商的账单、余额或后台管理接口。
- 新的 simpleLLMCall、聊天整段/流式、原生工具调用写入明确结果、服务商、配置 ID、耗时与已收到的 HTTP 状态。连接尚未收到响应时 HTTP 状态为空。
- 成功表示模型调用已返回并通过相应的响应解析/内容校验，不代表后续工具动作全部成功。动作参数不完整的原生流式记录标为失败。
- 主动取消与超时分别记录为取消和失败。HTTP 200 后发生解析/流中断仍可为失败。
- 旧记录只对明确失败格式做兼容，其余标为未知，不推断成功，也不补造耗时和 HTTP 状态。
- 工坊专用日志环维持隔离，仍在工坊查看。页面不覆盖所有 fetch、模型列表请求、生图、语音等网络活动。
- 日志按原有数量与体积预算滚动保留；正文会截断。新错误文本和监控页尽量遮盖密钥，但正文可能含个人对话信息，分享前仍应人工检查。

## 验证状态

本次仅进行了源码复核；工坊当前工具不能执行终端命令或自动操作浏览器，因此尚未运行 TypeScript 检查、Next.js 构建与真机交互测试，不应将本说明视为测试通过报告。

部署前请在本地运行 `npx tsc --noEmit` 和 `npm run build`，并完成下列人工验收：

- 开关快捷操作后只有一个贴边入口；贴边偏好仅影响提示词查看器。
- 左右拖动、松手吸边、刷新记忆、旋屏及外壳缩放后坐标仍正确。
- 菜单四个入口可用；返回、关闭、空白处点击和 Escape 正常；菜单不遮住状态栏或越过屏底限制。
- API 和世界书的全局/角色绑定保持原语义；API 详情中的拉取模型、连接测试与确认应用可用。
- 小卷在没有先点击桌面组件时也能从菜单打开，关闭后没有残留悬浮球，对话仍保留。
- 正常模型请求完成后记录出现，刷新与筛选可用，详情中的模型、时间、耗时和 HTTP 状态与实际一致。
- 对已有失败、取消、旧记录做只读检查：失败不算成功、旧记录未知，工坊日志未混入。
- 清空记录有二次确认且不删除聊天记录；分享报错前检查隐私遮盖。
